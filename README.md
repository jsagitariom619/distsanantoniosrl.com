# Distribuidora San Antonio — Web comercial

Proyecto público e independiente del ERP administrativo.

## Configuración pendiente

- Número corporativo y datos de contacto: dist/js/config.js
- Catálogo público autorizado: dist/data/catalog.js
- Información institucional definitiva: dist/index.html

El número de WhatsApp debe escribirse en formato internacional, sin signo más, espacios ni guiones.

## Verificación de demostración

Abrir la web con el parámetro ?demo=1 permite probar el flujo completo con productos claramente identificados como demostrativos. Estos productos no aparecen en la visita normal.

## Despliegue

El proyecto está preparado como sitio estático. En Vercel, la carpeta de salida es dist.
